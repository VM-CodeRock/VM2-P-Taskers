Scope and Technical Requirements

The D4U4 system is a cloud-native, browser-based application launched in September 2018. It serves as a centralized repository for forms and data within ICE Homeland Security Investigations (HSI) Division 4, Unit 4. The platform uses Amazon Web Services (AWS) and open-source technology to execute digital workflows and store investigative data. Factual

ICE requires Operation and Maintenance (O&M) services covering five functional modules: tracking, workflow management, records retention, reporting and analytics, and financial management/accounting workflow processing — all built using Agile software development. Factual

Scope Summary (RFI Language): ICE seeks a business-centric approach to system design — minimizing duplicative tasks, leveraging common functionality, reducing maintenance complexity, and using open architecture best practices. All work shall be accomplished through cloud-based hosting and DevSecOps tools within ICE's Agile environment.

Anticipated High-Level Task Areas:

  • O&M Support including Agile Planning and Support Services
  • Troubleshooting, corrective, preventative, and adaptive maintenance
  • Minor and moderate backlog changes
  • Help desk / user support
  • Backup and data management
  • System integration maintenance
  • Upgrades and refactoring
  • DevSecOps engineering support

AWS Lambda AWS ECS Amazon Athena Amazon RDS Amazon QLDB / DynamoDB Amazon SageMaker Open-Source CI/CD Pipeline Agile / Scrum DevSecOps Financial Mgmt Workflow

  • Financial management enhancements — workflow automation and ledger software
