KPMG Deploys Claude to 276,000 Staff — Big Four AI Consolidation Accelerates

Source: Build Fast with AI, May 28, 2026

KPMG and Anthropic announced the KPMG Digital Gateway Powered by Claude, embedding Claude into KPMG's global client delivery platform across 276,000 professionals in 138 countries. The alliance begins with tax and private equity clients and expands to all advisory services, with full implementation on Microsoft Azure by September 2026. Only EY has not made an equivalent announcement — a gap that has itself become a competitive signal. Combined, the three deployments represent approximately 1.1 million professionals globally with Claude access by September 2026.

    Claude Code v2.1.152: /usage Breakdown, PowerShell Security Fix, Free Security Plugin

    Claude Code shipped four consecutive point releases (v2.1.149–152), including: a /usage command showing per-category cost breakdowns for skills, subagents, plugins, and MCP servers; keyboard-friendly diff scrolling; GitHub Flavored Markdown task list rendering; and an enterprise MCP setting allowAllClaudeAiMcps. Separately, Anthropic released a free security-guidance plugin that runs three review stages during development sessions — reducing security-related PR comments by 30–40% in internal rollouts. The plugin is free on all plans and requires Claude Code version 2.1.144 or later. (Help Net Security, May 27)

    If you run Claude Code on Windows/PowerShell, run claude update or winget upgrade Anthropic.ClaudeCode immediately. The free security plugin is a direct time saver for code review cycles.

Agentic & Automation
  • MCP Protocol — Week of May 21, 2026

    MCP Gets Its Biggest Rewrite: Stateless Core, Extensions Framework, NSA Security Guidance BD Watch

    The maintainers of the Model Context Protocol locked the release candidate for MCP 2026-07-28, its largest revision since launch. The centerpiece is a stateless protocol core — removing the session ID, initialize handshake, and resumable streams, enabling ordinary HTTP infrastructure without persistent connections. An Extensions framework allows capabilities to ship independently. Two extensions arrive with it: MCP Apps (server-rendered UIs, so tools can return real interfaces) and Tasks (handling long-running minutes-to-hours jobs). Authorization now aligns with OAuth and OpenID Connect. The same week, the NSA's AI Security Center published a 17-page Cybersecurity Information Sheet (U/OO/6030316-26) specifically on MCP security design considerations, naming serialization flaws, trust boundary failures, unverified task propagation, and session weaknesses as core risks. (AI Weekly / DEV Community, May 27 · Intelligence Community News, May 22)

    Changeis relevance: The NSA guidance is the first formal Federal security treatment of MCP — directly applicable to any agentic Federal system proposal. Plan now for the stateless migration before the July 28 final spec. Audit MCP servers for the access controls the NSA flags; the protocol will not enforce them for you.

    Ketch Agent Network: Multi-Agent Orchestration for Enterprise Privacy & AI Governance

    Ketch launched the Ketch Agent Network, a multi-agent orchestration layer for enterprise privacy programs that continuously reasons across legal obligations, internal policies, and operational realities simultaneously. The platform auto-populates DPIAs, PIAs, TIAs, and AI impact assessments from live system data; continuously compares configurations against current regulations; and deploys purpose-built agents to remediate gaps. CEO Tom Chavez: "The work of running a privacy program doesn't fit in one context window, and it never did." The system has been in production for months. (Help Net Security, May 28)

    Changeis relevance: Multi-agent privacy/compliance orchestration is precisely the architecture pattern applicable to Federal AI governance requirements — NIST AI RMF, FISMA, FedRAMP compliance reasoning. Ketch's design pattern is worth studying for building Changeis's own compliance advisory tooling.

    Stack Overflow Research: Agentic AI Remains Mostly Human-Supervised in Production

This contrasts with the vendor narrative of fully autonomous multi-agent loops. (Stack Overflow Blog, May 27)

    For Changeis BD: supervised agentic systems with human approval checkpoints are the near-term sweet spot for Federal contracting — full autonomy remains aspirational. Proposals should frame agentic workflows with explicit oversight architecture.

Federal AI & GovTech
Directly Relevant — Federal Contracting Strategy

Brookings Report: Federal AI Spending Hit $91.8 Billion in Potential Awards in 2026 — DoD Controls 98.9%

  • Explosive market growth: Federal AI spending data from 1,743 contracts (September 2023–March 2026) shows obligated value surged to $7.2 billion (up 966% from $675M in 2024) and potential award value reached $91.8 billion (up 1,912% from $4.6B). The number of federal agencies with AI contracts grew from 17 in 2022 to 28 in 2026. (Brookings Institution, May 28)
  • DoD dominance: The Department of Defense's AI contract potential value rose 1,605% to $90.7 billion — representing 98.9% of total federal AI spending. HHS is a distant second at $138M. NAICS codes 54 (Professional, Scientific, Technical Services) and 51 (Information) represent 98% of all federal AI spending — precisely Changeis's market segment.
  • Vendor consolidation: Large established vendors — Booz Allen Hamilton, Palantir, and Accenture Federal Services — now dominate by contract value. Small businesses represent 34% of contracts by count but a much smaller share of value. The market is maturing, shifting toward firm-fixed-price contracts as agencies grow confident in scoping AI work.
  • Anthropic removed from DoD ecosystem: Brookings notes the DoD's public disagreement with Anthropic over autonomous weapons use earlier in 2026 as an example of the ethically contested space — underscoring the importance of vendor relationship strategy for any Federal AI play.
  • Federal AI Policy — May 28, 2026

    White House AI Executive Order Delayed Again — Voluntary Pre-Deployment Safety Framework Stalled Policy Watch

    President Trump again postponed signing an AI executive order that would establish a voluntary framework for government review of AI models before release. The administration cited concerns that mandatory pre-deployment testing would impede innovation. The proposed framework would have required AI developers to voluntarily share models with the government for safety testing ahead of public release — a provision informed by concerns raised by Anthropic's Mythos Preview earlier in May. Procurement compliance obligations meanwhile continue forming through enforcement, procurement standards, and state law simultaneously. (PilieroMazza PLLC, May 28 · JD Supra, May 27)

    The governance vacuum is a double-edged opportunity: Federal agencies will increasingly write their own AI governance requirements into contracts, making Changeis's advisory capability on AI governance architecture a defensible BD differentiator before a uniform framework arrives.

Tools & Skills Worth Trying
  • Developer Tools — May 28, 2026

    Claude Code Security-Guidance Plugin: Free, Three-Stage Vulnerability Scanning During Development

    Anthropic's new free security plugin for Claude Code runs three review stages: lightweight pattern checks during file edits (no model call, no cost), a full git-diff analysis after each model turn, and a deep review of surrounding files and sanitizers at commit/push time. It flags injection flaws, insecure deserialization, authorization bypass, SSRF, and weak cryptography. Teams can add custom rules for repository-specific security checks. Requires Claude Code 2.1.144+ and Python 3.8+. Install with claude plugin install security-guidance (or via the Claude Code plugin registry). (Help Net Security, May 27)

    Zero cost to try, immediate impact on code review quality. For Changeis development workflows and any agentic system work, this plugin catches issues before they reach human reviewers.
  • Infrastructure — May 27, 2026

    Red Hat Ansible + MCP: Patch RHEL CVEs Without Leaving Your IDE

    The Ansible community forum documented a new workflow using MCP to orchestrate RHEL vulnerability patching entirely within the IDE: the AI assistant calls a Lightspeed MCP server to identify affected systems, then calls an Ansible Automation Platform (AAP) MCP server to find the right job template and launch the patch job, with job output returned inline for review. This pattern extends to any RHEL fleet management task and demonstrates how MCP's tool-chaining model works in a real Federal IT operations scenario. (Ansible Community Forum, May 28)

    For Changeis IT modernization work: this MCP + Ansible pattern is directly demonstrable in Federal IT proposals as a zero-UI agentic ops workflow — concrete, auditable, and already documented on an open forum.
For the Builder — One Actionable Tip
Try This Today — Claude Code /usage + Security Plugin Audit

Run two commands inside your next Claude Code session. First, type /usage after a moderate working session to see exactly where your token budget goes: skills, subagents, plugins, and each MCP server broken out individually. Identify which MCP connections are consuming the most budget without proportionate output. Second, install the free security-guidance plugin (claude plugin install security-guidance) if you have not already, then open an existing project and make one small edit — watch the first-pass pattern check run instantly without a model call. Review the commit-time deep scan output on your next push. Both take under five minutes and deliver actionable insight: one optimizes your agentic spend, the other closes a compliance gap before it reaches code review. This pairs directly with this week's NSA MCP guidance: log every tool call with its identity and parameters, because you cannot investigate what you did not record.
