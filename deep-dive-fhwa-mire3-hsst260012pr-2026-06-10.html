4. MIRE 3.0 Background & Context
VersionYearKey ChangesElements
MIRE 1.02010Initial formal standard, 202 elements across segments/alignment/junctions202
MIRE 2.02017Enterprise DB transition, HPMS/ARNOLD alignment, modern operational elements205
MIRE 2.1Sept 2025Latest update; modern DB environments, Federal dataset alignment, FDE compliance support205+
MIRE 3.02026–27 (TBD)This contract: expected to add CAV data elements, active transportation (bike/ped), smart infrastructure, enhanced analytics integration, post-Sept 2026 FDE compliance pathwayTBD

Policy driver: 23 CFR §924.11(b) requires all states to have access to MIRE FDEs on all public roads by September 30, 2026. Post-deadline, FHWA must evaluate state compliance and determine next-generation MIRE requirements — creating the impetus for MIRE 3.0. Key FHWA POCs: Dr. Carol Tan (carol.tan@dot.gov) and Sarah Weissman Pascual (sarah.pascual@dot.gov).


Integration landscape: MIRE feeds into HSIS (Highway Safety Information System), CRSS (Crash Report Sampling System), FARS, HPMS ARNOLD, and state HSIP programs. Enhanced data analysis in MIRE 3.0 will likely involve predictive safety modeling (e.g., network screening, SPFs — Safety Performance Functions), integrating roadway geometry with crash causation data.
