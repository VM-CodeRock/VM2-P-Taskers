1. System Overview

VM2 is a fully automated AI task pipeline built on Perplexity Computer. It receives work instructions via email, direct chat, or Todoist, executes them through AI agents, publishes HTML deliverables to a password-protected Railway web portal, and backs up everything to Dropbox and GitHub automatically. As of June 6, 2026, the repo contains ~972 deliverables across 9 active scheduled crons (reduced from 14 on 2026-06-03 per cost optimization directive).

5. GitHub & Railway Hosting

5.1 Push Workflow

# Standard deliverable push
git add <filename>.html portal.html
git commit -m "Deliverable: <slug> · VM2 · YYYY-MM-DD"
git pull --rebase origin main   # resolve any concurrent pushes
git push origin HEAD
# Railway auto-deploys within ~60 seconds

5.2 Non-Fast-Forward Recovery (v4.5)

Resolution for non-fast-forward push failures: git pull --rebase origin main then git push origin HEAD. Never use force-push — risks overwriting concurrent deliverables.
