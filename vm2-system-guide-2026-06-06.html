load_skill Failure in Cron Subagents — Workaround (Issue #7)

Background crons CANNOT load user skills via load_skill(). This is a known platform behavior, not a bug. The workaround is to read skill files directly from disk:

1
Instead of load_skill(name="changeis-style"), use the read tool on the file path: /home/user/workspace/skills/user/changeis-style/Changeis_Refined_Document_Style.md
2
Apply the same pattern for any user skill. The SKILL.md or primary markdown file contains all needed instructions.
3
Cron instructions should explicitly reference the read-from-file workaround in their preamble going forward.
