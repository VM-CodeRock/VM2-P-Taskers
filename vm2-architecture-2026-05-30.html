1. System Overview

VM2 is a fully automated AI task pipeline built on Perplexity Computer. It receives work instructions via email, direct chat, or Todoist, executes them through AI agents, publishes HTML deliverables to a password-protected Railway web portal, and backs up everything to Dropbox and GitHub automatically. As of May 30, 2026, the repo contains ~945 deliverables across 14 active scheduled crons.

5. GitHub & Railway Hosting

5.1 Push Workflow

# Standard deliverable push
git add <filename>.html portal.html
git commit -m "Deliverable: <slug> · VM2 · YYYY-MM-DD"
git pull --rebase origin main   # resolve any concurrent pushes
git push origin HEAD
# Railway auto-deploys within ~60 seconds

5.2 Non-Fast-Forward Recovery (v4.5)

Resolution for non-fast-forward push failures: git pull --rebase origin main then git push origin HEAD. Never use force-push — risks overwriting concurrent deliverables.

5.3 HTML Requirements

  • All HTML must be plain HTML — no StaticCrypt encryption
  • Railway nginx basic auth protects all pages server-side
  • Deliverables should include a “Continue This Work” footer panel with context for follow-up sessions
  • Context slug at write-time (v4.5): Slug must be added at deliverable creation time, not via post-hoc retrofit.
  • NEW Issue #16 (5/30): Compliance Audit 6494d39d flagged 7/13 deliverables as non-compliant context slug (missing JSON block, Session Context panel, Continue This Work, or cost_estimate). This is a systemic gap — retrofit required.
  • External committers (Open Issues #9, #17): eBuy ledger, FMCSA Motus, MAPS daily monitor commit as “VM2 <vm2@changeis.com>” but are NOT in the 14 documented crons. NEW: commit fe3d3656 on 5/29 by FMCSA Motus — possible rogue cron from old session (Issue #17).
